# アイデア置き場 — 将来の機能・ストーリー展開

## メインストーリー進行

### コーデックス編（伏線：ver. 8.0.0 で仕込み済み）

**概要**  
古代魔導文明の知識が封じられた禁断の魔導書「コーデックス」をめぐる謎の物語。

**仕込んだ伏線**

| 場所 | 内容 |
|------|------|
| `lore.html` — NPC「セイファス・ノワール」 | コーデックスの名を知る謎の人物。問い詰めた者の記憶を消す能力を持ち、ギルドマスターとのみ交渉する。台詞に「知ってしまったなら……もう遅い」という含み。 |
| `lore.html` — NPC「ミレイア・フォンターヌ」 | 古代文字の羊皮紙を手帳に挟む姿が目撃されている。名門魔術学院を去った「ある事情」が未解明。 |
| `lore.html` — りゅうおうの伝承 | 「コーデックスの古いページには『竜王の真の姿を見た者は、世界の真実を知り、そして沈黙を選ぶ』との一文が記されている」という記述。コーデックスが竜王とも繋がる暗示。 |

**将来のクエスト案**

- コーデックスの断片を集めるクエスト（各ページが特定のモンスターに守られている）
- セイファスの正体暴露イベント
- ミレイアが魔術学院を去った理由の解明
- コーデックスを完成させると「隠しボスりゅうおう（強化版）」が解放される
